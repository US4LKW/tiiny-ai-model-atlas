CONNECT · STORE · UPDATE

Your Tiiny. Your catalogue.

Network access is only initiated on your request. The catalogue stays usable without the device.

01 / Direct API

The key is stored unencrypted in localStorage, not in the HTML or JSON. Use your own browser profile. HTTP sends it over the LAN without TLS.

GET /api/v1/models/online_models

02 / JSON beside the HTML

Select the folder containing the HTML and grant read/write access. A page cannot discover and access that folder on its own.

Tiiny_online_models.json

Without folder access, a normal download is used. You choose the destination and overwrite behaviour; the browser may add a (1) suffix.

03 / Import & local copy

JSON from Tiiny_API_sync.py is still supported. Drop it on the page or select it. The last valid snapshot is kept in browser storage.

Cannot connect? Browser limitations

A direct request works only when the device is reachable and Tiiny permits CORS for the page. Authorization triggers an OPTIONS preflight. HTML cannot override that check.

The browser may ask for Local Network Access permission. If access, DNS/mDNS, CORS or the network fails, use JSON import. Do not disable browser security.

Folder access is not supported by every browser and requires a secure context. Availability is detected at runtime. Permission may need to be granted again. Persistent storage for file:// depends on the browser and file path.

On opening: accessible linked-folder JSON → browser-cached snapshot → built-in data. Invalid JSON does not destroy the current catalogue. The two HTML files may have separate settings but can read the same JSON.
